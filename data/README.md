# Example Data

These files are copied from [PyHydroGeophysX `examples/data`](https://github.com/geohang/PyHydroGeophysX/tree/main/examples/data) and limited to the datasets the notebooks in this repository read. Third-party data keep an `acknowledgement.txt` beside the files; please cite those sources when you use the data. Data credited to Hang Chen are distributed under the repository licence (`LICENSE`, Apache-2.0).

| Path | Contents | Source | Terms |
| --- | --- | --- | --- |
| `ERT/DAS/` | Time-lapse DAS-1 ERT acquisitions and electrode positions | Thayer et al. (2018), Water Resources Research | See `acknowledgement.txt` |
| `ERT/E4D/` | Time-lapse ERT acquisitions in E4D format | Uhlemann et al. (2024), Water Resources Research | See `acknowledgement.txt` |
| `ERT/Bert/fielddataline2.dat` | Field ERT line | Hang Chen | Repository licence |
| `Seismic/srtfieldline2.dat` | Field seismic refraction line | Hang Chen | Repository licence |
| `climate/` | Daily weather at the Mt. Snodgrass monitoring site | Daymet Version 4 R1, ORNL DAAC, https://doi.org/10.3334/ORNLDAAC/2129 | Cite the dataset; `acknowledgement.txt` |
